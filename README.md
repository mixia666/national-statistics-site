StatAtlas: population, GDP, jobs, prices and life expectancy for 26 countries, each figure with its source and year — search, rank, and open any country's page.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The site is plain static files under `app/` (no build step, no network requests); `main.ts` hands it in by copying `app/` and `screenshots/` to the output directory and writing `dossier.json`.
